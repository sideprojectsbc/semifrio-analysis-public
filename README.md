# Semifrio: quem fala por cima de quem

Independent side project, **not connected to RTP**: an analysis of how often the commentators of the programme *Semifrio*
talk over each other, episode by episode.

The website is the folder [`docs/`](docs/) (a static site, published with GitHub Pages: Settings, Pages, branch `main`,
folder `/docs`). Everything is computed in the browser from the CSV files in `docs/data/`; `docs/clips/` holds short audio
excerpts so readers can check each overlap.

The numbers come from an automatic analysis of the audio and may contain errors. They measure moments of overlapping
speech, not intentions or conduct. Contact: sideprojectsbc@gmail.com


check it here: https://sideprojectsbc.github.io/semifrio-analysis-public/
